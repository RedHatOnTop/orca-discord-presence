# 2026-09-26 — Idle card

- Discord publishes one Playing activity at a time. With the Orca card and a test card on two IPC sockets, Vesktop's `LocalActivityStore` held both but `PresenceStore` published only the first. A second daemon would race the Orca card for the slot.
- The daemon now owns the slot. Orca keeps it while any agent is working or waiting, and for `IDLE_GRACE_MS` (5 minutes) after, so a turn boundary does not swap cards. After that, or when Orca is down, the card from `ORCA_PRESENCE_IDLE_CARD` takes over on its own application id. A cold start with nothing live shows the card at once.
- The side giving up the slot is cleared before the other is set. A channel publishing `null` never connects just to clear.
- The card file lives in `discord-profile/presence/idle-card.json`. `parseIdleCard` enforces Discord's limits: 128-character text, at most 2 buttons with 32-character labels, https URLs. A bad file logs `idle card disabled` and the daemon runs Orca-only. Edits need a service restart.
- Custom Profile Board widgets were not an option: the account's Add Widget picker lists only 관심사 and 게임 통계.
